# API Reference

The full Rust API documentation, generated by **rustdoc** straight from
the source and co-hosted under this site at `/api/`.

The reference is built reproducibly by Nix (the `api-docs` flake output,
a crane `cargoDoc` build) and copied into the published site during the
docs deploy. It carries full rustdoc fidelity: intra-doc links, the
source-code view, and search.

Three crates are documented:

<ul markdown>
  <li><a href="../api/rdf_shapes_core/index.html"><code>rdf_shapes_core</code></a> — the portable core (all business logic).</li>
  <li><a href="../api/rdf_shapes_wasm/index.html"><code>rdf_shapes_wasm</code></a> — the <code>#[wasm_bindgen]</code> shims.</li>
  <li><a href="../api/rdf_shapes/index.html"><code>rdf_shapes</code></a> — the native CLI.</li>
</ul>
